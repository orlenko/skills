Read [README](README.md), [SECURITY](SECURITY.md), the relevant plugin's
instructions, and current Git status/diff before changing source. Preserve
concurrent work and coordinate quality-process changes with the canonical
repository's single setup owner, recorded in the [local adoption record](docs/software-quality.md).

This repository adopts the [manual review workflow v0.2][workflow] and its
[centralized role instructions][roles] from source
`36b0b858b293e14af726e0adf58af476334ccd5d`, prospectively from this integration.

existing stronger authority, privacy, compatibility and integration gates remain.

Manual source-process adoption does not enable the inspection-only runner's
target checks or provision its enforced reviewer. It changes no runtime policy,
schema, configuration, lock or artifact pin and grants no new operational access.
